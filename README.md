## Project
사용자의 예술적 취향과 위치 기반 데이터를 결합하여 맞춤형 전시 및 문화 예술 콘텐츠를 추천하는 스마트 큐레이션 서비스입니다. 복잡한 탐색 과정 없이 개인화된 예술 경험을 손쉽게 즐길 수 있도록 돕습니다.

## Target User
- 미술관, 갤러리, 팝업스토어 등 문화 예술 행사를 정기적으로 즐기거나 관심이 많은 2030 관람객
- 주말이나 여가 시간에 방문할 감각적인 전시 및 문화 공간을 찾고 있는 사용자
- 본인의 예술 작품이나 전시 일정을 대중에게 알리고 소통하고 싶은 신진 아티스트 및 기획자

## Problem
- 흩어져 있는 전시 및 갤러리 정보로 인해 관심 분야에 맞는 문화 행사를 찾기 번거로움
- 난해한 예술 분야 특성상 개인의 취향에 맞는 전시를 선별하기 어려움
- 지역 소규모 전시나 신진 작가 팝업의 경우 홍보 창구가 부족하여 잠재 관람객과의 연결이 제한적임

## Core Feature
- **취향 기반 맞춤 큐레이션**: 사용자 관심 장르 및 관람 이력 기반 AI/알고리즘 추천
- **위치 기반 전시 맵 탐색**: 내 주변 실시간 전시·갤러리·팝업 위치 및 운영 정보 제공
- **디지털 도슨트 & 리뷰**: 작품 해설 정보와 관람객의 생생한 평점 및 사진 리뷰 공유
- **아티스트 & 전시 북마크**: 선호하는 작가나 공간의 신규 전시 알림 구독

## Tech Stack
- Mobile: Android (Kotlin)
- Frontend: React / Next.js
- Backend: Node.js (Express), Spring Boot
- Database: PostgreSQL, Firebase
- DevOps & Tools: Git, GitHub Desktop, GitHub Actions
